# Claims Oversight Simulator

A browser-based learning simulation. You run claims operations at a fictional health insurer and decide how much humans should check the AI that recommends denying care. 8 quarters, about 20 minutes, works on phones.

**Play:** open `index.html` in any browser, or visit the GitHub Pages link for this repository.

Built for the *Building Learning Simulations* workshop (Prof. Chad Kennedy, ASU).
For teaching only: the company is fictional, and the numbers are simplified estimates, not forecasts. Sources are listed inside the game.
